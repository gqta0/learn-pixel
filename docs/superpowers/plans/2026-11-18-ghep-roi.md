# Ghép rối (puppet) Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans; no push, no PR — stop and report so the user can look first.

**Goal:** A "Ghép rối" mode in Lò Pixel: the user hand-draws the flat parts of a 64 px character (HEAD sheet 118×79, BODY sheet 76×99 (whole build matched to the reference rigs; cells laid out by meaning: near limbs left of the trunk, far limbs mirrored on the right, flaps below): taller chest cell, six optional far-limb cells (`far_parts`; empty = near art darkened) and three robe flaps driven by the thighs, a port of `tools/flaps.py`) and sees them posed on the 15-bone rig of Project Genesis, playing any of its 14 clips, while drawing. Then bakes every clip to sprite sheets for the game.

**Architecture:**
- `data/puppet.json` — copy of `character-animation/out/puppet/puppet.json` (`genesis.puppet.v1`). Refresh: in the character project run `PYTHONPATH=tools python tools/export_puppet.py`, then copy `out/puppet/puppet.json` over `data/puppet.json` and run the tests (they check the format and a few joint positions).
- `js/puppet.js` — pure, no DOM, tested in Node: `frameAt` / `joints` (port of `tools/bones.py`), `placements` (which part sits on which bone and how far it turns), `bake` (port of `tools/character.py draw`: nearest-neighbour inverse rotation around the joint, groups back to front, per-group 1 px `#251c24` outline under all colours of the group, far parts ×0.8), fixed frame box for every clip, blockout sheets from `shapes`, shading suggestion, sheet lint, export naming.
- `js/puppetview.js` — DOM: the "Ghép rối" tab in the right column, the floating mini preview on the canvas, guides drawn by `render.js` through a hook, export ZIP.
- Guides are **not layers**: they are drawn by `render()` under (blockout) and over (cells, names, joints, anchors, slot zones) the pixels, toggled per kind and locked by construction, so they can never be exported or painted on. The drawing knows it is a puppet sheet through `doc.puppet = 'head' | 'body'` (saved, undone, in the library).
- Confine to cell reuses the selection: with "Khoá trong ô" on, a stroke starting in a cell sets `view.sel` to that cell (one hook in `input.js`), so `put()` already refuses pixels outside.
- Shading preview reuses `raster.setPreview` (the composite already shows it); commit is one undo step.

**Constraints:** no new dependency, no build, existing tests keep passing, Vietnamese UI, panel usable on phone (mini preview floats over the canvas; full panel is a right-column tab, reachable from 💾 File on phone).
